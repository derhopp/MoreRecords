# MoreRecords 0.1.0b3 — Beta 3

**Experimental pre-release for Home Assistant.** Existing releases remain available.

## Verified history for very rarely changing entities

- CCU-Historian source-completeness verification now tolerates **additional Home Assistant Recorder rows repeating the last verified source value**. This avoids rejecting otherwise complete histories because Home Assistant recorded extra identical `on` or `off` samples.
- Every CCU-Historian observation must still appear at its timestamp with the same state. Extra state **changes**, missing measurements and conflicts fail verification. The SHA-256 fingerprint covers **all current Recorder rows**, including repeats; later changes or purges invalidate the certificate in LightAway.
- Coverage remains scoped to the particular presence or light entity and the user-confirmed Historian interval. Plain CSV imports never certify continuity.
- Regression tests cover permissible duplicates and rejected additional/missing/conflicting changes; PRs now run CI checks before merging.

## Safety and installation

The importer still writes to private Home Assistant Recorder internals. Make a restorable backup before using import, and test on your precise Home Assistant version. Install `0.1.0b3` with HACS pre-releases enabled, restart, and explicitly re-verify complete source history for each relevant entity. Do not confirm coverage unless the original CCU-Historian stream is complete. Changes during Historian outages cannot be proven from a sparse stream alone.

This release does not retroactively certify CSV history, create synthetic Recorder runs, or change the live entity state.
