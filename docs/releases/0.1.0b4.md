# MoreRecords 0.1.0b4 — Beta 4

**Experimental pre-release for Home Assistant.** Always back up the complete Home Assistant configuration and Recorder database before testing.

## Rolling retention anchors

- Preserve each entity's latest **actually observed** Recorder state preceding the active `now - purge_keep_days` cutoff in `.storage/more_records_retention_anchors_v1`, **outside** Recorder's purge tables.
- Refresh anchors at integration startup and daily at **04:00 Home Assistant local time**, ahead of Home Assistant's usual scheduled auto-purge. Advance per-entity snapshots as new observations cross the cutoff; do not silently regress previously saved anchors.
- No fake events are inserted in the Recorder database; automatic purge continues to delete expired raw states normally.
- Add an optional **Reconstruct initial state** mode to CSV export. If a previous real Recorder row or saved anchor precedes the export start, export a *derived* state at the requested start timestamp, followed by raw Recorder observations. The raw export remains unchanged by default.
- The reconstructed export is marked with a `_reconstructed.csv` filename and distinguished in the preview. This is a timestamped inferred start state **not** an observed state change. The two-column CSV format remains compatible with MoreRecords' importer, but does **not** prove historical continuity.

## Important limits

- A snapshot taken after an older observation has already been purged **cannot recover** that lost value. Unexpected/manual purges, downtime across scheduled captures, recorder outages, changes not recorded, or an unsupported Recorder database can leave gaps.
- Existing Recorder and CCU-Historian verified-coverage behavior is unchanged. Anchors are not a source-completeness certificate and are not included in raw Recorder exports or Home Assistant's native History UI.
- Anchors are per entity and retain the original observed timestamp; they are used only if strictly before the export start. For times before the first known observation, no state can be inferred. If no observations exist within the window or before it, no result is manufactured.
- The experimental storage and SQLite Recorder query behavior still require live verification on the target Home Assistant version.

## Installation

Enable HACS prereleases for `https://github.com/derhopp/MoreRecords`, install **0.1.0b4**, restart Home Assistant, and allow MoreRecords to perform its initial snapshot. Open **Settings → Devices & services → MoreRecords → Configure → Export CSV** to enable reconstruction for a selected export. Existing releases remain available.
